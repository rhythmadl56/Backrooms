A real-time multiplayer **CLI chat app** inspired by the Backrooms. Connect, create rooms, meet random users, and chat entirely from your terminal.

## ✨ Features

- 🖥️ Interactive terminal UI
- 👤 Custom & random usernames
- 🏠 Custom rooms with unique room codes
- 🎲 Random room joining
- 💬 Real-time room-based chat
- 👥 Global online users
- ⌨️ Built-in command system
- 👉 `/poke <username>` nudge feature
- 🔄 Automatic reconnection
- 🌐 Publicly deployed backend

## 🛠️ Tech Stack

`Node.js` · `JavaScript` · `Socket.IO` · `Blessed` · `Figlet` · `Render` · `Git/GitHub`

## 🚀 Run Locally

```bash
git clone <YOUR_REPO_URL>
cd Backrooms

cd server
npm install
node index.js
```
In another terminal:

cd client
npm install
node client.js
🌐 Access

The client connects to the publicly deployed Backrooms server, so you can play with other users over the internet.

No browser. No fancy UI. Just your terminal and whoever's online.
